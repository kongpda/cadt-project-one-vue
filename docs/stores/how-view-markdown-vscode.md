# Previewing This Documentation

To preview this markdown documentation in VS Code:

1. **Using Built-in Preview**

    - Press `Ctrl+Shift+V` (Windows/Linux) or `Cmd+Shift+V` (Mac) to open preview in split view
    - Or press `Ctrl+K V` (Windows/Linux) or `Cmd+K V` (Mac) to open preview side-by-side
    - Alternatively, click the preview icon in the top-right corner of the editor (icon looks like an open book)

2. **Using Extensions**

    - Install "Markdown All in One" extension for enhanced preview features
    - Install "Markdown Preview Enhanced" for additional styling options
    - These extensions provide live preview as you type

3. **Preview Settings**
    - Customize preview appearance in VS Code settings
    - Search for "markdown.preview" to see all available options
    - You can modify themes, font size, and line width

The preview will automatically update as you make changes to the markdown file.
